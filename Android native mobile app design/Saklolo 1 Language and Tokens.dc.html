Hinahon

The Saklolo design language. Hinahon means composure: the steady voice of a dispatcher who has done this a thousand times. Every token below is a Material 3 role, so it drops into a Compose MaterialTheme.

Assumption. PRD.md, SPEC.md and demo.html weren't in the upload, so copy is drafted from the brief. English is the default language; Filipino is a switch that adds a second line under each string. The 20-byte layout and eval numbers are placeholders. Send the PRD and I'll swap in its strings.
Not using the project's default system (Chop). It uses red for errors and green for money, which breaks the reserved triage rule. Hinahon is built from scratch on stock M3.

Principles

01
One thing at a time
Isa-isa lang

Each victim screen has one instruction and one primary action. The status card is the only other thing on screen. If two things compete (CPR and a question), one is visibly on top and the other waits.

02
Voice first, buttons always
Boses muna, laging may pindutan

The phone speaks every instruction and listens for every answer. OO / HINDI / HINDI SIGURADO and the incident tiles never disappear, so a failed model, a loud storm or a quiet voice never blocks a report.

03
Never colour alone
Hindi kulay lang

Triage is colour + word + shape, every time. Red, yellow and green belong to triage only. The brand is blue. Status that isn't triage (on the way, silent, worse) uses ink, outline and icons.

04
Honest about what's known
Tapat

Show what the phone understood as facts, with a one-tap fix. Unknown looks unknown (dashed, "?"). The beacon says "sending, no answer yet" until an ACK arrives. Nothing looks more connected than it is.

Triage: reserved colours

Not M3 roles. Define them as a separate TriageColors object so no M3 component can pick them up by accident. Same fill in every theme; yellow gets a 1.5 dp ink outline on light surfaces for glare.

Colour roles · Material 3

Victim is dark-first: true-black background so most of an OLED screen is off. Rescuer light is built for sun: pure white, pure black ink, 2 dp black outlines instead of shadows. The brand primary is blue in every theme. M3 error is mapped to the 911 red and used only by the 911 button; there are no form errors in this app.

Type scale

Atkinson Hyperlegible Next, designed for low-vision readers: distinct 1/l/I and 0/O, open counters that survive a cracked screen. Mono for bytes and data. Victim body starts at 18 sp; nothing safety-relevant goes under 16 sp. All sizes in sp, so 130% system scaling applies.
