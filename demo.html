Saklolo · the offline 911 dispatcher

When the towers fall, no one answers 911. Saklolo answers, offline: a local model understands a panicked Taglish report, asks for what's missing, guides first aid, and compresses the emergency into a 20-byte Bluetooth beacon that rescuers can rank, hear and follow.

      How this prototype works, and the decisions it made where the PRD is silent or inconsistent

      Simulated vs. real

      • Simulated: the Gemma calls (rule-based stand-ins with the same output schema and validator), Bluetooth between the two mockups, GPS (a fixed demo location in General Luna, Siargao), and the rescuer's walk. Voice uses the browser's speech API where it exists (Chrome), otherwise type.
      • Real logic, the same as planned for the app: the 20-byte codec (exact byte layout), the triage rule, follow-up selection, the "getting worse" rule, the protocol engine with safer branches and entry steps, ranking, bearing and distance, RSSI smoothing, the validator and the dictionary baseline.
      • The Eval panel's "model" column is the stand-in, so its score proves nothing. It only shows what the Eval screen will look like. The dictionary column is a fair baseline: it knows the same keywords and number words, but not negation, corrections or context.

      Proposed PRD/SPEC changes found while building this

      • Demo sentence. The PRD sentence had no drowning word, so no model could honestly output DRN, and its "hindi humihinga" is an exact phrase that a fair dictionary would catch. This prototype uses "Tatlo kami, ay hindi, apat pala, kasama si lola. Nalunod yung bata, hindi na humihinga!": "nalunod" gives DRN, and "hindi na humihinga" is a negation the dictionary's phrase list honestly misses.
      • "Getting worse" is decided on the victim phone and sent as 1 bit (the spare bit in byte 13). The rescuer can't tell new information from a worsening situation: comparing records, the first report after a bare SOS (YELLOW → RED) and the answer "nasa bubong kami" (trapped 0 → 1) would both look "worse", and the flag would be on all the time. The victim phone knows which facts were unknown, so filling in an unknown fact never counts as worse.
      • An SOS with no facts yet is YELLOW (the PRD rule would make it GREEN, ranking a silent SOS below "we're fine").
      • CPR never waits for a follow-up question. When a life threat is heard (not breathing, heavy bleeding), the protocol card goes first and the follow-up question sits below it, marked "answer when you can".
      • Children get a flag (the spare bit in the flags byte). Drowning is the leading cause of death for Filipino children, but "child" wasn't in the vulnerable list.
      • "Kasama" counting rule: "apat kami, kasama si lola" means 4 including grandma; "tatlo kami at si lola" means 4. A real model must be tested on both.
      • People unknown is 0 in the people byte, and "no GPS fix" is Int.MIN_VALUE in lat/lon.
      • Dead phones stay on the board with their last location and a red "last heard 40 min ago". One seeded record shows this.
